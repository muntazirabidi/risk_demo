## 🆘 If Something Goes Wrong

### "Failed to fetch" error
- Check backend is running: http://localhost:3001/api/health
- Restart: `cd backend && npm start`

### Slow response
- First request may take longer (normal)
- Use well-known companies for faster results
- Typical time: 18-45 seconds

### Rate limit error
- Wait 15 minutes
- Or restart backend to reset counters (demo only!)
